# 3.1 不断学习

## 3.1.1 问题

程序员是一个需要终生学习的岗位。

技术迭代太快，每时每刻都有新技术产生。学一个新的框架、一门新的编程语言，在这个行业里算是小事，是应该做到的事。

AI 出现以后，多了一句更硬的话：简单、重复的活，不再需要人来做。

那么要提升的是什么？

## 3.1.2 一个比较激进的说法

本文作者的观点比较激进：编程语法、第三方库 API 的调用熟练程度，将不再重要。

这些交给 AI 就行。

人类工程师真正要长的，是逻辑思维能力和设计能力。

这个说法听起来顺，也有点道理。但它有一个说不通的地方。

## 3.1.3 说不通的地方

工程师的成长路径里，本来包含"一行一行写代码"这样的实践。

不是因为它有多少产出价值，而是因为很多东西只能从这上面长出来：这句代码为什么错、这个边界为什么漏了、这一版为什么被打回来。这些都不是读文档能读会的。

现在简单的代码没有人写了。将来的工程师，怎么走完这一段？
